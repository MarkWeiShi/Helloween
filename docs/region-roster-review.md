# 世界地图 20 区与鬼怪名单审核稿

2026-10-28 · 地图结构已实现；新增角色名单待审核。

**现有 40 个角色全部保留，新增候选 46 个；若全部批准，角色总数为 86。** 候选数量不代表制作承诺，也未加入游戏、奖励或排行榜。中文音译为工作名。

地图采用六大区域入口，进入后选择文化分区。俄罗斯在亚洲和欧洲入口均可发现；阿拉伯世界在亚洲和非洲入口均可发现，但只有一个分区记录。爱尔兰归入其他欧洲，文化标签保留 Ireland。玩家国家归属与地图分区独立。

20 区是全球发现框架；当前角色并没有覆盖每个国家或全部族群。非洲、其他欧洲、南亚与太平洋等大区应继续补充内部地域与族群。南极可作为景观，不杜撰当地传统鬼怪。

## 每区文化标签与审核重点

现有角色的完整介绍与来源见 [文化资料](cultural-sources.md)。以下候选仅供名单选择，地方版本、外形和具体故事文案仍待逐项研究。

### 中国 / China

- 保留：**Jiangshi**（僵尸）— Chinese folk narratives。
- 保留：**Nie Xiaoqian**（聂小倩）— Pu Songling's Liaozhai Zhiyi, China。
- 保留：**Yingning**（婴宁）— Pu Songling's Liaozhai Zhiyi, China。
- 保留：**Painted-Skin Ghost**（画皮鬼）— Pu Songling's Liaozhai Zhiyi, China。

### 日本 / Japan

- 保留：**Kappa**（河童）— Japanese river folklore。
- 保留：**Bake-danuki**（化け狸）— Japanese tanuki folklore。
- 保留：**Chochin-obake**（提灯お化け）— Japanese lantern-yokai imagery。
- 保留：**Kasa-obake**（唐傘お化け）— Japanese umbrella-yokai imagery。

### 韩国 / Korea

- 保留：**Dokkaebi**（도깨비）— Korean dokkaebi traditions。
- 保留：**Gumiho**（구미호）— Korean fox traditions。
- 保留：**Bulgasari**（불가사리）— Korean bulgasari legends。
- 保留：**Gaekgwi**（객귀）— Korean traditions of spirits away from home。

### 其他东亚与中亚 / Other East & Central Asia

- 待审：**阿尔玛斯 / Almas** — 蒙古地区；山野传说生物。
- 待审：**舒尔穆斯 / Shulmus** — 蒙古民间叙事；妖灵。
- 待审：**铜爪妖 / Zheztyrnak** — 哈萨克等中亚传统；山野妖怪。
- 待审：**阿尔巴斯特 / Albasty** — 中亚突厥语文化传统；妖灵。

### 印度与南亚 / India & South Asia

- 待审：**毗陀罗 / Vetala** — 印度梵语故事传统；附尸灵，拟采用谜语故事版本。
- 待审：**楚蕾尔 / Churel** — 南亚多地传统；女鬼，需确定具体地方版本。
- 待审：**佩特妮 / Petni** — 孟加拉文化区域；女鬼。
- 待审：**夜呼灵 / Nishi** — 孟加拉文化区域；夜间呼唤的灵怪。

### 东南亚 / Southeast Asia

- 保留：**Krahang**（กระหัง）— Thai krahang traditions。
- 保留：**Phi Kong Koi**（ผีกองกอย）— Thai forest folklore。
- 保留：**Nang Tani**（นางตานี）— Thai traditions surrounding kluai tani banana plants。
- 保留：**Krasue**（กระสือ）— Thai krasue traditions。
- 保留：**Tikbalang**（Tikbalang）— Philippine tikbalang traditions。
- 保留：**Kapre**（Kapre）— Philippine kapre traditions。
- 保留：**Duwende**（Duwende）— Philippine household and landscape traditions。
- 保留：**Santelmo**（Santelmo）— Philippine light stories, including Arteche, Eastern Samar。
- 泰国 4 角与菲律宾 4 角合并展示；越南、印尼、马来西亚等已纳入发现范围，角色后续补充。

### 俄罗斯 / Russia

- 待审：**家宅精灵 / Domovoi** — 俄罗斯／东斯拉夫传统；家宅守护精灵。
- 待审：**森林精灵 / Leshy** — 俄罗斯／东斯拉夫传统；森林守护者。
- 待审：**鲁萨尔卡 / Rusalka** — 东斯拉夫传统；水边灵体，各地版本不同。
- 待审：**芭芭雅嘎 / Baba Yaga** — 俄罗斯／斯拉夫童话；林间巫婆或试炼者。

### 阿拉伯世界 / Arab World

- 待审：**古尔 / Ghul** — 阿拉伯民间故事；荒野变形怪。
- 待审：**伊夫里特 / Ifrit** — 阿拉伯文学与民间故事；精灵类别。
- 待审：**马里德 / Marid** — 阿拉伯文学与民间故事；精灵类别。
- 待审：**纳斯纳斯 / Nasnas** — 阿拉伯奇谈；奇异半身生物。
- 使用具体文学／民间故事版本；不将精灵统一解释为亡魂，不把游戏结局写成真实宗教仪式；四者并不是四个国家的代表。

### 非洲 / Africa

- 待审：**托科洛什 / Tokoloshe** — 南部非洲恩古尼语文化等；小型灵怪。
- 待审：**卡拉诺罗 / Kalanoro** — 马达加斯加地方传统；山野精灵。
- 此组只覆盖部分西非、南部非洲与马达加斯加传统，不代表全非洲。北非可关联阿拉伯分区，东非与中非角色仍需补充。

### 大洋洲与太平洋 / Oceania & Pacific

- 待审：**班耶普 / Bunyip** — 澳大利亚东南部相关原住民传统；水域传说生物。
- 待审：**塔尼瓦 / Taniwha** — 新西兰毛利文化；守护者或危险水域生灵，依部族叙事。
- 待审：**雾山精灵 / Patupaiarehe** — 新西兰毛利文化；山林超自然族群。
- 待审：**梅内胡内 / Menehune** — 夏威夷／波利尼西亚；传说中的建造者。
- 各角色不能代表所有原住民或太平洋岛民；保留具体文化和地方版本，守护者的结局优先采用继续守护，避免统一“超度”。Menehune 使用夏威夷文化标签，玩家仍可选择美国归属。
